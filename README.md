# 🌤️ Weather App

A simple weather app built with HTML, CSS, and JavaScript using Open-Meteo API.

## Features
- Search weather by city name (limited to Iran)
- Current temperature, precipitation, wind speed
- Weather condition with emoji
- Error handling for invalid cities and no internet

## Technologies
- HTML5
- CSS3
- JavaScript (Vanilla)
- Open-Meteo API
